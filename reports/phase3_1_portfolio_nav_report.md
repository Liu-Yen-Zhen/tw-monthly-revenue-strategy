# Phase 3.1 Portfolio/Cohort NAV 回測雛形

這是 portfolio NAV 雛形，不是正式交易系統。它把每月選股 cohort 轉成可複利的 NAV 序列，並比較 benchmark NAV 與 excess NAV。

## 方法

- 每個 revenue_month 形成一個等權 cohort。
- 分別測 20/40/60 交易日持有期。
- 策略、benchmark、excess 都用月 cohort return 複利。
- benchmark 為對應 entry/exit window 的上市+上櫃等權報酬，已扣 0.7% round-trip cost。
- `industry_capped` 版本限制每月單一產業最多 6 檔。
- 價格仍為未調整價格；結果只作研究判斷。

## 解讀重點

- 這一步已經從單筆/單月平均報酬，升級成可複利 NAV 指標。
- 若 60 日與產業上限版本仍優於 benchmark，代表月營收基本面動能值得正式化。
- 但此版本仍不是正式級：尚未使用調整價、未做日級重疊持倉資金配置、未處理漲跌停/停牌/非成交。
