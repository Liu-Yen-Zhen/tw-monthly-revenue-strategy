# Phase 2.5 探索性 Proxy 回測報告

這不是正式回測，也不是交易建議。它使用保守 usable date proxy 與未調整收盤價，只用來判斷是否值得繼續研究。

## 設計

- 月營收：MOPS 靜態歷史月營收彙總，2021-01 至 2026-04。
- 價格：TWSE/TPEx 官方日行情，2023-01 至今，未調整價格。
- 訊號可用日 proxy：營收月份次月 11 日後第一個交易日。
- 每月最多 Top 20，等權 cohort。
- 成本：來回 0.7%。
- 持有期：20/40/60 個交易日。

## 主要限制

- 未用逐公司公告 timestamp。
- 未處理除權息/現金股利/股票股利，長持有期報酬可能有偏差。
- 未建立完整 portfolio NAV、重疊持倉、產業上限、非成交/漲跌停限制。
- 未對 benchmark 計算超額報酬。
- 若結果不好，可以早停；若結果好，也只代表值得做正式回測。
