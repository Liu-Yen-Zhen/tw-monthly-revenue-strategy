# Paper-Trading Template

This template is for research / paper-trading only. It is not a live order ticket.

## Monthly workflow

### 1. Data availability check

- Confirm the monthly revenue source has been updated.
- Record the actual observation time.
- Do not assume a company was tradable before the data was visible.

Required fields:

```text

data_source:
data_observed_at:

```

### 6. Assumption drift review

After each monthly cycle, answer:

1. Did the real signal list match the backtest rule?
2. Were any names impossible to enter because of limit-up / suspension / illiquidity?
3. Was slippage larger than the model assumption?
4. Did actual data timing differ from `usable_date_proxy`?
5. Did electronics / semiconductor names dominate the selected book?
6. Did one or two winners dominate monthly PnL?
7. Should this month be marked as model-valid, execution-impaired, or data-timing-impaired?

## Acceptance threshold before production-adjacent claims

Do not call the strategy production-adjacent until at least several monthly cycles have:

- timestamped signal generation;
- feasible paper fills;
- explicit non-fill accounting;
- stable slippage / cost assumptions;
- documented performance versus historical proxy expectations;
- no hidden same-day look-ahead assumption.
